# Gardenhouse 店頭ノート（Webアプリ版）

苗・野菜の在庫、店頭数、写真、店頭販売期限、販売価格、出荷先をスマホで記録するアプリです。
Claude のアカウントがなくても、スマホのブラウザで開いて**お店の暗証番号**を入れれば使えます。

- データの保存先：Google の Firebase（Firestore）。7人・写真付きの使い方なら無料枠に収まる見込みです（概算）。
- 置き場所：GitHub Pages（無料）。アドレスは `https://<GitHubのユーザー名>.github.io/<リポジトリ名>/` になります。
- 電波が弱くても開けます。記録は端末にためておき、つながったら自動で送られます。

## 準備の手順（Patrickさんにお願いすること）

### 手順1　GitHub を用意する

1. https://github.com で無料アカウントを作ります。
2. 右上の「＋」→「New repository」で、名前を `tento-note` にして **Public** で作ります（中身は空のままで大丈夫です）。
   - Public にするのは、無料で GitHub Pages を使うためです。公開されるのは画面のプログラムだけで、在庫や写真のデータは公開されません。
3. https://claude.ai/connect-github を開いて、GitHub を Claude につなぎます。
4. 作ったリポジトリのアドレス（例：`github.com/gardenhouse/tento-note`）をスレッドで教えてください。

### 手順2　Firebase を用意する

1. https://console.firebase.google.com を会社の Google アカウントで開き、「プロジェクトを作成」。名前は `gardenhouse-tento` など。Google アナリティクスはオフで構いません。
2. プロジェクトの画面で「</>（ウェブ）」のアイコンを押し、アプリ名 `店頭ノート` で登録します。
   - 表示される `firebaseConfig = { apiKey: ..., authDomain: ..., ... }` の部分をそのままコピーして、スレッドに貼ってください（秘密の情報ではありません）。
3. 左のメニュー「構築」→「Authentication」→「始める」→「メール / パスワード」を**有効**にします。
   - 「ユーザー」タブ →「ユーザーを追加」で
     - メールアドレス：`staff@gardenhouse-farm.jp`（実在しなくて構いません。変える場合は教えてください）
     - パスワード：**お店の暗証番号**（6桁以上の数字）
   - 「設定」タブ →「承認済みドメイン」に `<GitHubのユーザー名>.github.io` を追加します。
4. 左のメニュー「構築」→「Firestore Database」→「データベースを作成」。
   - 場所は `asia-northeast2（大阪）` か `asia-northeast1（東京）`。
   - 「本番環境モード」で作成し、「ルール」タブに [firestore.rules](firestore.rules) の中身を貼って「公開」します。

### 手順3　Claude が仕上げる

設定値とリポジトリのアドレスを受け取ったら、Claude が `config.js` に設定を入れて GitHub に置きます。
そのあと、リポジトリの「Settings」→「Pages」で「Branch: main / root」を選んで保存してください（1回だけ）。
できあがったアドレスを、パートの皆さんに配ります。

## 現場での使い方

1. 配られたアドレスをスマホで開き、暗証番号を入れます（一度入れれば次からは不要）。
2. 共有メニューから「ホーム画面に追加」すると、アイコンから開けます。
3. 右上の「担当」で自分の名前を入れます。
4. 操作は A4 の操作ガイドと同じです。

暗証番号を変えたいときは、Firebase の「Authentication」→「ユーザー」でパスワードを変更します。変えたあとは全員がもう一度入れ直します。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 画面の枠 |
| `style.css` | 見た目 |
| `app.js` | 動き（在庫・期限・出荷先の判定、保存） |
| `config.js` | お店ごとの設定（Firebase の値、共通アカウント） |
| `firestore.rules` | データを読み書きできる人の決まり |
| `manifest.webmanifest`, `sw.js`, `icons/` | ホーム画面アイコンと、電波が弱いときの表示 |

試作版（Claude の中のページ）のデータは、担当の名前を入れる画面の「データを取り込む（JSON）」から移せます。
